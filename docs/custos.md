# 9. Custos e Orçamento

Esta seção apresenta uma estimativa de custos para o desenvolvimento e manutenção do sistema Coliseum Gym, considerando valores aproximados de mercado. Os valores apresentados têm caráter acadêmico e servem apenas como referência.

---

## 9.1 Custos de Desenvolvimento

| Item | Descrição | Valor Estimado |
|-----|----------|----------------|
| Análise de Requisitos | Levantamento, modelagem e documentação do sistema | R$ 2.000,00 |
| Design de Interface (UI/UX) | Criação de protótipos e identidade visual | R$ 1.500,00 |
| Desenvolvimento Front-end | Implementação das telas e navegação | R$ 4.000,00 |
| Desenvolvimento Back-end | Regras de negócio, controle de dados e lógica do sistema | R$ 5.000,00 |
| Banco de Dados | Modelagem e implementação | R$ 2.000,00 |
| Testes e Validação | Testes funcionais e correções | R$ 1.500,00 |

**Custo estimado de desenvolvimento:** **R$ 16.000,00**

---

## 9.2 Custos de Infraestrutura (Estimativa Mensal)

| Item | Descrição | Valor |
|-----|----------|-------|
| Hospedagem do Sistema | Servidor em nuvem (Vercel ou similar) | R$ 100,00 |
| Banco de Dados | Serviço em nuvem (PostgreSQL) | R$ 80,00 |
| Armazenamento | Arquivos e backups | R$ 50,00 |
| Domínio | Registro anual (.com.br) | R$ 40,00 |

**Custo mensal estimado:** **R$ 230,00**  
**Custo anual estimado:** **R$ 2.760,00**

---

## 9.3 Considerações sobre o Orçamento

Apesar de o desenvolvimento deste projeto ter sido realizado em ambiente acadêmico, utilizando ferramentas gratuitas, os valores apresentados refletem uma estimativa realista de mercado para sistemas com funcionalidades semelhantes.

Essa estimativa auxilia na compreensão do investimento necessário para a implementação do sistema em um cenário real.
